## What's new in this update?

This update primarily focuses on refining the **UI and layout of the List Views**. 

I gave the app's list screens a visual makeover to make them look more modern and in detail than default layout. Instead of plain text, list items now feature `StatBox`, `MetricBlock`, `LetterAvatar`, and `StatusPill` to show stats (Passed, Failed, GPA, Pass rate) at a glance.
